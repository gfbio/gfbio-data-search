GFBio Search

Find, filter, map and collect biodiversity datasets from across Germany's research data centers — all from a single search.

The GFBio Search portal is the public gateway to biodiversity data held across the German Federation for Biological Data (GFBio). From a single search you can discover datasets contributed by certified data centers and partner institutions all over Germany, and reuse them following the FAIR data principles.

It is operated by GFBio e.V. as part of NFDI4Biodiversity, Germany's National Research Data Infrastructure for the biological sciences. Behind the search box, a wider infrastructure gathers, validates and harmonises metadata so that one query can reach across many different data sources at once.

Contribute data: Are you a data center or institution that would like to publish data through GFBio? Datasets are registered and prepared for harvesting in the GFBio data services — get in touch with us to start contributing.

What this service does

Discover biodiversity data in one place

The Search portal brings together biodiversity metadata from many sources into one searchable place. You do not need to know which institution holds a dataset, or which standard it was described in — search once, and the portal looks across them all.

How the system fits together

From data center to your search results

GFBio Search is built from a handful of cooperating parts. Data centers register with the Data Provider Manager; the harvester then collects metadata from every source and translates the many input standards into one shared format; the harmonised records are stored in a single search index; and the portal lets you discover them.
